# J-SAFE｜北海道レッカー・ロードサービス シネマティックLP

1ページ完結型LP。`index.html` 1ファイルで動作し、外部依存はGoogle Fontsのみ（読み込み失敗時もフォールバック表示）。

```
jsafe/
├ index.html          … LP本体（HTML/CSS/JS 内包）
├ privacy.html        … プライバシーポリシー
└ assets/
   ├ video/           … 背景動画（未配置でも表示崩れなし）
   └ img/             … poster画像・OGP画像
```

---

## 1. 公開前に差し替える箇所

`index.html` 内を検索して置換してください。該当行には `▼` コメントが入っています。

| 対象 | 現在の値 | 置換先 | 出現箇所 |
|---|---|---|---|
| 電話番号（表示） | `0120-000-000` | 実番号 | index 10か所（aria-label含む） |
| 電話番号（リンク） | `tel:0120000000` | ハイフン無し実番号 | index 15か所 / privacy 1か所 |
| 公式LINE | `https://lin.ee/XXXXXXX` | 公式LINE URL | index 8か所 |
| 会社名 | `[会社名]` | 実社名 | index 2 / privacy 2 |
| 所在地 | `[所在地]` | 実住所 | index 4（構造化データ含む）/ privacy 1 |
| 営業時間 | `[営業時間]` | 例）24時間365日受付 | index 5 / privacy 1 |
| 対応エリア | `[対応エリア]` | 例）札幌市および近郊 | index 4か所 |
| canonical / og:url | `https://example.com/` | 本番URL | head |

一括置換の例：

```bash
sed -i 's/0120-000-000/011-000-0000/g; s/tel:0120000000/tel:0110000000/g' index.html privacy.html
```

構造化データ（`AutomotiveBusiness`）内の `telephone` `openingHours` `streetAddress` も同時に更新してください。
現状 `openingHours` は `Mo-Su 00:00-23:59`（24時間受付）で入っています。実態と異なる場合は必ず修正してください。

## 2. 動画の入れ方

`assets/video/` にファイルを置くだけで自動的に再生されます（HTML編集不要）。

| ファイル名 | 内容 |
|---|---|
| `scene01-approach` | 雪道でスタックした車へ、遠くからレッカー車が近づく（FV・最終CTAで使用） |
| `scene02-callcenter` | 女性オペレーターがコールセンターで電話対応 |
| `scene03-blizzard` | 吹雪の北海道道路を救援車両が走る |
| `scene04-winch` | 雪道でスタックした車をウインチで安全に救援 |
| `scene05-ditch` | 側溝へ脱輪した車両の救援 |
| `scene06-driver` | 作業終了後、ドライバーとスタッフが安心して会話 |

各シーンにつき最大3ファイル（あるものだけでOK）：

- `<name>.webm` … 優先再生（VP9 / 2〜4Mbps）
- `<name>.mp4` … fallback（H.264 / 1920×1080）
- `<name>-sp.mp4` … スマホ用軽量版（720×1280 or 1280×720 / 1〜1.5Mbps）
- `assets/img/scene0X.jpg` … poster画像（1600×900程度、WebP/AVIF可）

推奨：**音声トラックなし・8〜15秒ループ・16:9**。仕様どおり cinematic / realistic / Japanese Hokkaido winter で統一。

### 動画を読み込まない条件（自動フォールバック）

以下のいずれかに該当する場合、動画は一切ダウンロードせず、CSSで作ったシネマティック背景のまま表示します。

- ファイルが存在しない
- `prefers-reduced-motion: reduce`
- 低速回線（`effectiveType` が 2g 系）／ブラウザの省データ設定 `saveData`
- 自動再生がブラウザにブロックされた

また画面外のシーンは `pause()` し、`IntersectionObserver` で可視領域に入ってから初めて読み込みます。

## 3. サービス項目の増減

`<article class="svc">` 単位で完結しています。提供していないサービスはその `<article>` ごと削除してください。
グリッドは自動で詰まります（`.no` の連番だけ手で振り直し）。同様に `#quicknav` のカードも `<a>` 単位で削除可。

## 4. ロゴの差し替え

ヘッダーの `<a class="logo">` 内のインラインSVG（`.logo__mark`）を差し替えるだけです。
`fill` にCSS変数（`--yellow` / `--navy`）を使っており、スクロール追従時に自動で青×白へ反転します。
支給ロゴが画像の場合は `<img class="logo__mark" src="assets/img/logo.svg" alt="">` に置き換え、
`.is-stuck .logo__mark` の色反転ルールを削除してください。

## 6. シネマティック演出の設計

映像素材が揃う前でも「映画的」に見えるよう、**演出はCSS/Canvas側に持たせ、動画は差し込むだけ**の構成にしています。

### 第一幕（オープニング）
ネイビーの幕にロゴが結像し、警告灯の光が回り、黄色いルールが引かれて幕が開きます。
**1.15秒／セッション中1回のみ／タップ・スクロール・キー操作で即スキップ**。
緊急サイトなので、幕はCSSアニメーションだけで必ず開く実装です（JSが止まっても固まりません）。
2回目以降は `sessionStorage` を見て `<head>` の時点で非表示にするため、ちらつきも出ません。

### シネマティック・カメラ
可視シーンだけを毎フレーム更新します。

- **ケンバーンズ** … スクロールに連動して `scale(1.13 → 1.03)` のゆっくりした寄り
- **パララックス** … ±1.8%（処方の上限±5%以内）
- **露出グレード** … シーンが画面中央に来ると `.scene__ov` が薄くなり、絵が開く
- 書き込むのは `transform` / `opacity` のみ。レイアウトは走りません
- 画面外のシーンは監視対象から外れ、rAFループ自体が止まります

### フィルムレイヤー
各シーンに `.scene__fx` を重ね、**フィルムグレイン**（SVGノイズを5ステップで揺らす）と
**ヴィネット**を乗せています。CSS製の背景でも実写でも同じ質感に揃います。

### 行送りタイポグラフィ
見出しは1行ずつ `overflow:hidden` のマスクから下端をくぐって立ち上がります
（1150ms / 130msずつ遅延）。映画のタイトルバックの文法です。

### 降雪（3層）
奥（小さく遅い）／中／手前（大きくボケる）の3層。焼き込み済みスプライトを `drawImage` するだけなので軽量です。
**`mix-blend-mode: screen` の前景レイヤー**なので、濃色シーンの上でだけ効き、白地セクションでは素通りして本文の可読性を落としません。

### 警告灯
FVと最終CTAで、レッカーの回転灯を模した光条（4.6秒/周）と、路面に落ちる光の明滅を重ねています。**ページの署名モーションはこれ1つ**に絞っています。

### セクションのリズム
明るさで割るのではなく、**色温度**で割っています。
FV（薄暮のアンバー）→ 吹雪（寒色）→ コールセンター（暖色）→ 雪中救援（寒色）→ 夕暮れ（暖色）。
コールセンターだけは、暗い画面の中で**唯一明るいもの**として白い電話CTAカードを置き、最大コントラストを確保しています。

## 7. 実装済みの技術要件

- **CV導線**：FV即2CTA／スマホ固定バー（電話60%・LINE40%、高さ64px）／各セクションに電話・LINE再掲
- **パフォーマンス**：動画は `preload="none"` ＋ 可視時のみ読み込み／画面外は `pause()`／
  低速回線・省データで動画スキップ／CLS対策／JS約7KB・外部ライブラリ0
- **アクセシビリティ**：電話番号はテキスト（`tel:`）で表示、タップ領域は全て44px以上、
  `prefers-reduced-motion` で幕・降雪・グレイン・警告灯・行送りを**全停止**、
  情報は動画に依存せずHTMLテキストで完結、`:focus-visible` にセーフティイエローのアウトライン
- **仕上げ処方**：ページ全体を1枚の連続背景（`.bg-canvas`）／SVGグレインでバンディング除去／
  濃色セクションは上下±150pxの移行帯（`.bleed`）＋映像側は `mask-image` で矩形の縁を消去／全メディアに同一カラーグレード
- **SEO**：title / description / canonical / OGP / Twitter Card / 構造化データ `AutomotiveBusiness`

### 表示保証（重要）

本文は「JSが動いているときだけ隠してから出す」設計です（`html.js` でスコープ）。
リビールは **IntersectionObserver に依存せず**、スクロールごとに未表示分だけを rAF で走査する確定的な方式で、
さらに 3.2 秒経っても何も表示されていなければ演出ごと解除されます。
JSが完全に止まっても、**必ず全文が表示されます**。緊急時に使うサイトのため、演出よりも到達性を優先しています。
